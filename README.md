 -Objetivo Geral do Projeto:
 Criar um programa na linguagem Go que trabalhe com o operador % e for.

 -Desafio parte 1:
 Criar um código que exiba todos os números entre 1 e 100 que são divisíveis por 3.

 -Desafio parte 2:
 Criar em formato de código uma antiga brincadeira: Ao falar os números sempre que aparecem um múltiplo de 3, o participante deve falar ''PIN'' e nos múltiplos de 5 o participante deve falar ''PAN''. 
 Então, o programa deve imprimir números de 1 a 100 e nos casos relatados, não devem aparecer os números, mas sim, o que o participante deve falar. 
 E quando o número para múltiplo de 3 e 5 deverá falar "PINPAN".
